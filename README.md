# Book Basket - MERN Application

Book Basket is a MERN (PostgresQL, Express.js, React.js, Node.js) application that allows me to upload books I have read, along with ratings and reviews, helping others explore and discover useful books. Users can view books uploaded with their ratings and reviews to explore and discover useful books. The application uses multiple APIs to automatically fetch and display book covers, enhancing the user experience by showcasing books with their visual representations.

## 🚀 Features
- **Upload Books**: I will add books I have read, including title, author, rating, and review.
- **Explore Books**: Users can browse books uploaded with ratings and reviews.
- **Book Covers**: Automatically fetches and displays book covers using APIs.
- **Interactive UI**: A clean and intuitive user interface for seamless browsing.

## 🛠 Installation & Setup
Clone the repository:
```sh
git clone https://github.com/your-username/book-basket.git
```
Navigate to the project directory:
```sh
cd book-basket
```
Install dependencies 
```sh
npm install
```
Start the server:
```sh
npm run server
```
Open [http://localhost:3000](http://localhost:3000) in your browser.
